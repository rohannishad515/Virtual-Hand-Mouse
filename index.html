Gesture Controls Guide

Cursor Move

Keep index finger open and move your hand naturally to control cursor coordinates smoothly.

Left / Right Click

Bring thumb and index close for **Left Click**. Bring index and middle fingers close for **Right Click**.

Both Hands Zoom

Use index fingers of both hands. Move them apart to Zoom In or closer to Zoom Out.

How to Run Locally

Run these commands in your terminal or command prompt to install dependencies and run the script:

pip install opencv-python mediapipe pyautogui
python app.py

Requirements:

  • Python 3.8+ installed
  • Webcam / Laptop Camera
  • `hand_landmarker.task` model file in your project folder
