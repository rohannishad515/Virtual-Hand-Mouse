Control Your PC Using Hand Gestures

A next-gen virtual mouse application that lets you move cursor, click, drag, scroll, and zoom using your webcam—no hardware required!

Gesture Controls Guide

Cursor Move

Keep index finger open and move your hand naturally to control cursor coordinates smoothly.

Left / Right Click

Bring thumb and index close for Left Click. Bring index and middle fingers close for Right Click.

Both Hands Zoom

Use index fingers of both hands. Move them apart to Zoom In or closer to Zoom Out.

Page Scrolling

Raise index and middle fingers together and move them up or down to scroll smoothly.

Drag & Drop

Keep thumb and index finger closed tightly and move your hand to drag files or windows.

How to Run the Script

1

Download Script

Click the Download Script button above to save the app.py file on your computer.

2

Install Requirements

Open your terminal or command prompt and run this command to install required libraries:
pip install opencv-python mediapipe pyautogui

3

Run the Program

Navigate to the folder where you downloaded the file and run it using Python:
python app.py
